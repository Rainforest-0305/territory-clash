본 게임 코드는 광고 네트워크의 SDK 를 직접 탑재하지 않고, 토스가 제공하는 광고 SDK(토스 광고 및 그 AdMob 브릿지)만 호출합니다. 토스 광고 SDK가 내부적으로 제3자 광고 네트워크와 연동되는지, 연동된다면 어떤 사업자인지는 본 게임 코드에서 확인할 수 없습니다. 확인할 수 없는 사항을 추측해 적지 않기 위해 이 문서에는 기재하지 않으며, 확인되는 대로 갱신합니다.

본 게임은 이름, 전화번호, 이메일, 계좌 정보, 위치 정보를 수집하지 않습니다. 인앱결제는 사용하지 않습니다. 순위(리더보드) 기능은 토스 SDK 프레임워크 자체에는 존재하나 본 게임 코드는 이를 호출하지 않아 점수를 서버로 전송하지 않습니다. 입력 리플레이(고스트) 데이터는 이용자가 설정에서 옵트아웃(수집 거부)할 수 있으며, 자신의 과거 기록과 겨루는 용도로만 이 기기 안에서 사용되고 다른 이용자에게 전송·공개되지 않습니다. 연령 확인 기능 (getDeclaredAgeRange)이 코드에 준비되어 있으나 현재 비활성 상태(enabled: false)로, 실제로 연령 정보를 요청하지 않습니다. 이를 활성화할지는 별도 정책 결정 사항입니다.

1-B. 웹 / Microsoft Store(PWA) 채널

이 채널은 빌드 시점에 위 토스 식별키·광고·이용 현황 집계 코드 자체가 번들에서 제거됩니다(src/toss-web 대체 모듈로 전량 치환 - 실제 배포 파일에 해당 코드가 없음을 확인했습니다). 인앱결제·광고·분석 도구가 없고, 페이지 로딩이 끝난 뒤에는 어떤 네트워크 요청도 하지 않는 완전 오프라인 게임입니다. 진행 데이터는 이 기기의 브라우저 저장소(localStorage)에만 저장됩니다.

2. 기기에 저장되는 정보

앱인토스 채널의 진행 데이터는 브라우저 저장소(localStorage)와 토스 앱 네이티브 저장소 두 곳에 나뉘어 저장됩니다. 웹/Microsoft Store 채널은 브라우저 저장소 (localStorage) 한 곳에만 저장됩니다. 모두 이 기기의 로컬 저장 영역에만 있으며, 진행 데이터·설정·출석 기록·광고 카운터 자체는 외부 서버로 전송하지 않습니다(위 1항의 이용 현황 집계·광고 SDK 통신은 예외이며 각각 별도로 기재했습니다).

3. 개인정보의 처리 위탁 및 제3자 제공

앱인토스 채널에서는 광고 표시를 위해 광고 SDK를, 이용 현황 집계를 위해 토스 앱인토스 로그 시스템(eventLog)을 사용합니다(4항 참고). 두 서비스 모두 이용자를 실명으로 식별하지 않는 범위에서만 데이터를 처리하며, 그 외 위탁 처리 업체나 제3자 제공은 없습니다. GitHub Pages·MS 스토어 채널은 광고·분석 관련 코드 자체가 빌드 단계에서 제외되어 이 항목이 적용되지 않습니다.
