# Territory Clash - PWA deploy folder

GENERATED by `store/build_pwa.py`. Do not hand-edit anything in this folder -
it is wiped and rebuilt on every run. Change the source or the script instead.

## The game

60-second rounds. You start on a small patch of ground; draw a trail out of your own territory and close the loop back into it to capture everything you enclosed. Cut through a rival's trail and 30 percent of their territory transfers to you - they respawn 0.4 seconds later. A player is eliminated only when they are reduced to zero cells. Largest territory when the clock runs out wins.

## Properties

- **Fully offline.** A service worker precaches the entire build on first load,
  so the game runs with no network at all afterwards.
- **No ads.** No ad SDK, no interstitials, no rewarded video.
- **No sign-in.** No account, no email, no login of any kind.
- **No data collection.** No analytics, no tracking, no telemetry. Nothing
  leaves the device; settings stay in local storage.

## Deploying

Publish this folder as the GitHub Pages root. `.nojekyll` is required: without
it Pages runs Jekyll, which strips any path beginning with an underscore -
that would silently 404 hashed asset paths and break the build.
